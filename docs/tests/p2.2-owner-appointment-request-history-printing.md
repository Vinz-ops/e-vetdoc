# [P2.2] Deliver owner appointment requests and appointment history

## Why This Task Mattered
This task enables pet owners to request appointments for their linked pets, view their appointment history and status, and print appointment details. It ensures that owners can only see and manage their own pets' appointments, maintaining privacy and security while providing a user-friendly interface for scheduling veterinary visits.
