# [P1.5] Deliver pet ownership and staff registry MVP

## Why This Task Mattered

Owners need to manage only their linked pets while staff and admins must be able to search the registry. This task establishes the sole ownership model (`pets` + `pet_owners` join table with permissions) and verifies role-based isolation — preventing owners from accessing other owners' pets while allowing staff/admin read access.

## What Was Verified

- `npm run lint`, `npx tsc --noEmit`, and `npm run build`: pass; no new warnings introduced.
- Database schema: `pets` table has MVP patient fields; `pet_owners` join table includes `relationship`, `is_primary_contact`, `can_view_medical_records`, `can_receive_notifications`; `pets` has no `owner_id` column.
- RLS policies enforce owner isolation and staff/admin read access.
